# Habla releases

Downloads and the update feed for **Habla**, a private, lightweight dictation app for the Mac.

- Download the latest version from the [Releases](https://github.com/Jason9347/habla-releases/releases/latest) page, or from [yeison.co.uk](https://yeison.co.uk).
- Habla updates itself; `appcast.xml` is the feed it checks.

Speech is turned into text on your Mac. Habla's source code is not published here.
